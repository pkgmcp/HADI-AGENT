API Reference مرجع API

Complete REST API documentation for all HADI endpoints. Base path: /api/v1

⚠️ All POST/PUT requests require Content-Type: application/json header.

Common Error Responses / پاسخ‌های خطا

    

      
StatusMeaningCommon Cause

      
422Validation ErrorMissing required fields, invalid role

      
429Rate Limit ExceededToo many requests per minute

      
404Not FoundUnknown agent or workflow ID

      
500Server ErrorAI provider failure, database error

        "role": ["The role field is required."],
        "content": ["The content field is required."]
    }

429 Rate Limit:
{
    "success": false,
    "message": "Rate limit exceeded. Please try again later.",
    "retry_after": 60
}


    
Request Headers / هدرهای درخواست

    

      
HeaderDescriptionRequired

      
Content-Typeapplication/json for POST/PUTYes

      
X-Session-IdSession tracking IDOptional

      
AuthorizationBearer token (if authentication enabled)Optional

    


    
💡 The X-Session-Id header is used for token tracking across requests. If not provided, an anonymous session ID is generated from the client's IP.
