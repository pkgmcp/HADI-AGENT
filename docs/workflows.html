Workflow Engine موتور گردش کار

The Workflow Engine enables multi-step, multi-agent task orchestration. Workflows are defined as a series of steps that can include AI prompts, function calls, conditional logic, parallel execution, and agent delegation.

Step Types / انواع گام

TypeDescriptionExample
promptSend a prompt to an AI providerGenerate code, analyze text
functionCall a PHP function/methodData transformation, API calls
conditionBranch based on previous resultCheck if output is valid
parallelRun multiple steps concurrentlyMulti-model analysis
agentDelegate to a specialized agentSecurity review, deployment

Creating a Workflow / ایجاد گردش کار

phpuse App\DTOs\WorkflowDTO;
use App\Services\MCP\WorkflowEngine;

$engine = app(WorkflowEngine::class);

$dto = new WorkflowDTO(
    name: 'Code Review Pipeline',
    steps: [
        [
            'name' => 'analyze_code',
            'type' => 'prompt',
            'prompt' => 'Review this Laravel code for bugs and issues: {{context.code}}',
            'config' => ['temperature' => 0.2],
        ],
        [
            'name' => 'security_check',
            'type' => 'agent',
            'agent' => 'security',
            'task' => 'Check code for OWASP vulnerabilities: {{results.analyze_code.content}}',
        ],
        [
            'name' => 'quality_check',
            'type' => 'condition',
            'condition' => 'not_empty',
            'source' => 'security_check',
            'on_true' => 'generate_report',
            'on_false' => 'request_changes',
        ],
        [
            'name' => 'generate_report',
            'type' => 'prompt',
            'prompt' => 'Summarize all review findings in a markdown report.',
        ],
    ],
    context: ['code' => $codeToReview],
);

// Create the workflow
$id = $engine->create($dto);

// Execute it
$result = $engine->execute($id);

echo "Status: {$result['status']}";
echo "Steps completed: {$result['steps_completed']}";

created ──► running ──► completed

              └──► cancelled
                    │
                    └──► retrying ──► running

Managing Workflows / مدیریت گردش کار

php// Check status
$status = $engine->status($workflowId);
// ['status' => 'running', 'current_step' => 2, 'total_steps' => 4, ...]

// Get specific step result
$stepResult = $engine->step($workflowId, 'analyze_code');

// Cancel
$engine->cancel($workflowId);

// Retry (resets errors and re-executes)
$retryResult = $engine->retry($workflowId);

// Get all active workflows
$active = $engine->getActiveWorkflows();

// Cleanup old workflows
$engine->cleanup(24); // Remove workflows older than 24 hours

Parallel Execution / اجرای همزمان

php$dto = new WorkflowDTO('Analysis Pipeline', [
    [
        'name' => 'parallel_analysis',
        'type' => 'parallel',
        'steps' => [
            [
                'name' => 'code_quality',
                'type' => 'prompt',
                'prompt' => 'Analyze code quality: {{context.code}}',
            ],
            [
                'name' => 'security_scan',
                'type' => 'prompt',
                'prompt' => 'Security scan: {{context.code}}',
            ],
            [
                'name' => 'performance',
                'type' => 'prompt',
                'prompt' => 'Performance analysis: {{context.code}}',
            ],
        ],
    ],
    [
        'name' => 'consolidate',
        'type' => 'prompt',
        'prompt' => 'Combine these reports into one: {{results.parallel_analysis}}',
    ],
]);

Error Handling / مدیریت خطا

php$dto = new WorkflowDTO('Resilient Pipeline', [
    [
        'name' => 'risky_step',
        'type' => 'prompt',
        'prompt' => 'Process data...',
        'continue_on_failure' => true, // Don't stop workflow if this step fails
    ],
    [
        'name' => 'backup_step',
        'type' => 'function',
        'function' => 'App\\Actions\\FallbackAction',
        'arguments' => ['data' => '$risky_step'],
    ],
]);

Function Steps / گام‌های تابعی

Call any invokable class or closure:

php// Using a class
$dto = new WorkflowDTO('Data Pipeline', [
    [
        'name' => 'transform',
        'type' => 'function',
        'function' => App\Actions\TransformDataAction::class,
        'arguments' => [
            'input' => '$previous_step',
            'format' => 'json',
        ],
    ],
]);

// Using a closure
Config::set('workflow.functions.hello', function ($name) {
    return "Hello, {$name}!";
});

$dto = new WorkflowDTO('Test', [
    [
        'name' => 'greet',
        'type' => 'function',
        'function' => function () { return 'Hello!'; },
        'arguments' => [],
    ],
]);
