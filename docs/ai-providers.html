AI Providers ارائه‌دهنده‌های هوش مصنوعی

HADI supports 5 AI providers out of the box, all implementing the AIProviderInterface. Providers are interchangeable — swap them without changing your business logic.

Supported Providers / ارائه‌دهنده‌های پشتیبانی‌شده

ProviderClassAPI Key RequiredCost Model
OpenAIOpenAIProvider.phpYesPer-model token pricing

💡 Ollama runs 100% locally — no API key needed. Ideal for development, testing, and offline scenarios.

OPENAI_TEMPERATURE=0.7

Provider Interface / واسط ارائه‌دهنده

All providers implement App\Interfaces\AIProviderInterface:

phpinterface AIProviderInterface
{
    public function send(AIRequestDTO $request): AIResponseDTO;
    public function stream(AIRequestDTO $request): iterable;
    public function name(): string;
    public function isAvailable(): bool;
    public function models(): array;
    public function calculateCost(int $inputTokens, int $outputTokens): float;
}

Provider Router Strategies / استراتژی‌های مسیریابی

Configure the routing strategy in .env:

envAI_ROUTING_STRATEGY=latency   # Options: latency, cost, random
AI_FALLBACK_ENABLED=true
AI_FALLBACK_PROVIDER=ollama   # Fallback when preferred provider fails

Using Providers Directly / استفاده مستقیم

php// Direct provider usage
$openai = app(\App\Services\AI\OpenAIProvider::class);

if ($openai->isAvailable()) {
    $response = $openai->send(
        new \App\DTOs\AIRequestDTO(
            prompt: 'Hello world',
            provider: 'openai',
            model: 'gpt-4o',
            temperature: 0.7,
            maxTokens: 4096,
        )
    );

    echo $response->content;
    echo "Cost: \${$response->cost}";
    echo "Latency: {$response->latencyMs}ms";
}

Streaming Responses / پاسخ‌های流

php// Stream from any provider
$provider = app(\App\Services\AI\AnthropicProvider::class);

foreach ($provider->stream($request) as $chunk) {
    echo $chunk;
    ob_flush();
    flush();
}

Adding a Custom Provider / افزودن ارائه‌دهنده سفارشی

Implement the AIProviderInterface and register it with the MCPServer:

phpuse App\Interfaces\AIProviderInterface;

class CustomLLMProvider implements AIProviderInterface
{
    // Implement all interface methods...
}

// Register with MCP Server
$server = app(\App\Services\MCP\MCPServer::class);
$server->registerProvider('custom-llm', new CustomLLMProvider);

// Or add to HadiServiceProvider
private function registerProviders(MCPServer $server): void
{
    // ... existing providers
    $server->registerProvider('custom-llm', app(CustomLLMProvider::class));
}
