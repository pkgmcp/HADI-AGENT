MCP Server سرور MCP

The MCP (Model Context Protocol) Server is the core routing and orchestration layer. It manages AI provider connections, tracks token usage, analyzes costs, maintains conversation context, and compresses prompts.

ProviderRouter / مسیریاب ارائه‌دهنده

The ProviderRouter handles intelligent AI provider selection with three strategies:

StrategyDescription / توضیحاتUse Case
latencyPicks provider with lowest historical latencyChat applications, real-time features
costPicks cheapest provider for given token countBatch processing, cost-sensitive workloads
randomRandom selection among available providersLoad testing, traffic distribution

If the preferred provider is unavailable, the router automatically falls back to the next best option:

php// Automatic fallback chain
$response = $router->routeWithFallback($request);
// Tries: preferred → next best → fail → throws RuntimeError

TokenObserver / ردیاب توکن

Real-time token tracking with storage, alerts, and session-level monitoring:

📊 Database Storage

All token usage persisted to mcp_token_usage table for historical analysis.

⚠️ Threshold Alerts

Configurable token thresholds trigger warning logs when exceeded.

💵 Cost Tracking

Per-provider and per-model cost tracking with daily accumulation.

📈 Cache Integration

Daily and session token counts cached for fast access.

php// Manual token tracking
$observer = app(\App\Services\MCP\TokenObserver::class);
$observer->track(
    provider: 'openai',
    model: 'gpt-4o',
    inputTokens: 150,
    outputTokens: 75,
    cost: 0.0045,
    latencyMs: 320,
    sessionId: 'user_session_123',
    action: 'mcp.handle',
);

// Get summary
$summary = $observer->summary('user_session_123');
// ['session_id' => '...', 'total_tokens' => 225, 'total_cost' => 0.0045]

CostAnalyzer / تحلیلگر هزینه

Track and analyze AI costs with budget management:

php$analyzer = app(\App\Services\MCP\CostAnalyzer::class);

// Record a response cost
$analyzer->record($aiResponse);

// Get full summary
$analyzer->summary();
// ['daily' => [...], 'by_provider' => [...], 'total' => 2.50]

// Budget utilization
$analyzer->budgetUtilization();
// ['budget' => 100.00, 'spent' => 12.50, 'remaining' => 87.50, 'utilization_percent' => 12.5]

// Project next 30 days
$analyzer->projection(30);
// 35.70 (estimated)

ContextManager / مدیر متن

Session-aware conversation context with automatic trimming:

php$manager = app(\App\Services\MCP\ContextManager::class);

// Build context from message (auto-trims if over limit)
$context = $manager->build($message);

// Add external context to session
$manager->addContext('session_123', [
    ['role' => 'system', 'content' => 'You are a helpful assistant.'],
]);

// Get current context size
$size = $manager->getContextSize('session_123');

// Summarize conversation
$summary = $manager->summarize('session_123');

PromptReducer / کاهش‌دهنده پرامپت

Intelligently compress prompts to fit within context limits:

MethodDescription
reduce()Checks context size and compresses if over threshold
compress()Summarizes older messages, keeps recent ones intact
foldMessages()Folds multiple messages into a single summary string
truncateToTokens()Truncates text to fit within a token budget
compressPrompt()Removes redundant blank lines and whitespace

MCPClient / کلاینت MCP

HTTP client for communicating with external MCP servers:

php$client = new \App\Services\MCP\MCPClient;
$client->setEndpoint('https://remote-mcp-server.com/api/mcp');
$client->setHeader('Authorization', 'Bearer token');

// Send message
$response = $client->send(new MCPMessageDTO('user', 'Hello remote MCP'));

// Stream response
foreach ($client->stream($message) as $chunk) {
    echo $chunk;
}

// Check health
$health = $client->health();
