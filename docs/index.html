Overview / نمای کلی

HADI (Hyper-Automated Development Intelligence) is a Laravel-native framework for building AI-powered applications. It provides a complete MCP (Model Context Protocol) server architecture, a multi-agent orchestration system, and a flexible workflow engine — all following clean architecture and SOLID principles.

HADI یک فریم‌ورک لاراولی برای ساخت برنامه‌های مبتنی بر هوش مصنوعی است. این سیستم شامل سرور MCP، معماری چندعاملی، و موتور گردش کار می‌باشد.

Quick Start / شروع سریع

bashcomposer require hadi/hadi-agent
php artisan vendor:publish --tag=hadi-config
php artisan migrate
برای شروع سریع، کافیست پکیج را نصب کرده، کانفیگ‌ها را انتشار دهید و میگریشن‌ها را اجرا کنید. 
php// Send a message to the MCP server
$response = app(\App\Services\MCP\MCPServer::class)->handle(
    new \App\DTOs\MCPMessageDTO(
        role: 'user',
        content: 'Generate a Laravel authentication system',
        metadata: ['provider' => 'openai']
    )
);

echo $response->content; // AI-generated response
