Getting Started شروع کار با HADI

Installation / نصب

HADI follows standard Laravel package conventions. Add the package via Composer:

bashcomposer require hadi/hadi-agent

Publish Configuration / انتشار تنظیمات

Publish the configuration files and migrations:

bashphp artisan vendor:publish --tag=hadi-config
php artisan vendor:publish --tag=hadi-migrations
php artisan migrate
با اجرای دستورات بالا، فایل‌های کانفیگ (mcp.php, agents.php, ai.php) و میگریشن‌های دیتابیس انتشار می‌یابند.

Service Provider / ثبت سرویس

Add the service provider to config/app.php:

php'providers' => [
    // ...
    App\Support\HadiServiceProvider::class,
],

Configuration / پیکربندی

Configure your AI providers in the .env file:

env# OpenAI
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o

# Anthropic
ANTHROPIC_API_KEY=sk-ant-...
ANTHROPIC_MODEL=claude-3-opus-20240229

# Ollama (local)
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama2

# Gemini
GEMINI_API_KEY=...
DEEPSEEK_API_KEY=...
💡 At least one provider must be configured. Ollama works locally without an API key. All other providers require a valid API key.

Quick Usage / استفاده سریع

1. Send a Message to MCP

php$server = app(\App\Services\MCP\MCPServer::class);

$response = $server->handle(
    new \App\DTOs\MCPMessageDTO(
        role: 'user',
        content: 'Explain Laravel queues',
        metadata: [
            'provider' => 'openai',
            'temperature' => 0.3,
        ],
    )
);

echo $response->content;
echo "Tokens: {$response->totalTokens()}";
echo "Cost: \${$response->cost}";

2. Execute an Agent

php$planner = app(\App\Services\Agents\PlannerAgent::class);

$result = $planner->execute(
    task: 'Design a microservices architecture for an e-commerce platform',
    context: ['domain' => 'e-commerce', 'scale' => 'medium'],
);

echo $result->content;

3. Create a Workflow

php$engine = app(\App\Services\MCP\WorkflowEngine::class);

$dto = new \App\DTOs\WorkflowDTO(
    name: 'Code Review Pipeline',
    steps: [
        ['name' => 'analyze', 'type' => 'prompt', 'prompt' => 'Review this code...'],
        ['name' => 'security', 'type' => 'agent', 'agent' => 'security', 'task' => 'Check for vulnerabilities'],
        ['name' => 'approve', 'type' => 'condition', 'condition' => 'not_empty', 'source' => 'security'],
    ],
);

$id = $engine->create($dto);
$result = $engine->execute($id);

Directory Structure / ساختار دایرکتوری

app/
├── Actions/
├── DTOs/              <- Data Transfer Objects
├── Http/
│   ├── Controllers/   <- MCP, Agent, Workflow controllers
│   ├── Middleware/     <- RateLimit, TokenTracking
│   ├── Requests/      <- Form request validation
│   └── Resources/     <- API resource transformers
├── Interfaces/        <- AIProvider, Agent, MCP, Workflow interfaces
├── Models/
│   ├── AI/            <- AgentExecution, WorkflowExecution
│   ├── MCP/           <- Conversation, TokenUsage
├── Repositories/      <- Data access layer
├── Services/
│   ├── MCP/           <- Server, Client, Router, Observer, Engine
│   ├── AI/            <- Provider implementations
│   ├── Agents/        <- 8 specialized agents
│   └── Workflows/     <- Workflow definitions
├── Support/           <- ServiceProvider, helpers
└── Traits/            <- HasTokens, HasLogger

Testing / تست

HADI ships with a comprehensive test suite. Run tests with Pest:

bash# Run all tests
./vendor/bin/pest

# Run specific test groups
./vendor/bin/pest --filter=MCP
./vendor/bin/pest --filter=Agents
./vendor/bin/pest --filter=Workflows

# Run with coverage
./vendor/bin/pest --coverage
