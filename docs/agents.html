AI Agents عامل‌های هوشمند

HADI ships with 8 specialized AI agents, each designed for a specific role. All agents extend the BaseAgent class and implement the AgentInterface.

BaseAgent / عامل پایه

Every agent inherits from App\Services\Agents\BaseAgent which provides:

  • Automatic token tracking via TokenObserver
  • Conversation history management
  • Provider routing with fallback via ProviderRouter
  • JSON response parsing
  • Session-scoped configuration

Available Agents / عامل‌های موجود

AgentClassPurposeDefault Provider
PlannerAgent PlannerAgent.php Analyzes requests, generates execution plans, estimates effort OpenAI
CoderAgent CoderAgent.php Generates production-ready code, refactors, explains code Anthropic

Usage / نحوه استفاده

php// Direct usage
$planner = app(\App\Services\Agents\PlannerAgent::class);
$result = $planner->execute('Design a REST API for a blog platform');

// Or via AgentController
$controller = app(\App\Http\Controllers\AgentController::class);
$controller->register('planner', $planner);

// Check if agent can handle a task
if ($planner->canHandle('plan a microservices architecture')) {
    $plan = $planner->createExecutionPlan('...');
}

PlannerAgent Methods / متدهای برنامه‌ریز

php$planner = app(\App\Services\Agents\PlannerAgent::class);

// Create execution plan

    task: 'Build authentication system',
    constraints: ['timeline' => '2 weeks', 'team_size' => 3]
);

// Estimate effort
$estimate = $planner->estimateEffort('Database migration script');

Creating Custom Agents / ساخت عامل سفارشی

Extend BaseAgent and implement the required methods:

phpuse App\Services\Agents\BaseAgent;
use App\DTOs\AgentDTO;

class CustomAgent extends BaseAgent
{
    public function __construct()
    {
        parent::__construct();
        $this->config = new AgentDTO(
            name: 'CustomAgent',
            type: 'custom',
            provider: 'openai',
            model: 'gpt-4o',
            temperature: 0.3,
            maxIterations: 5,
        );
    }

    public function canHandle(string $task): bool
    {
        return str_contains(strtolower($task), 'custom');
    }

    protected function systemPrompt(): string
    {
        return 'You are a custom agent specialized in...';
    }
}
